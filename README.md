# MSFFNet
Code for the paper "MSFFNet: Multimodal Spatial–Frequency Fusion Network for RGB-DSM Remote Sensing Image Segmentation"

## Requirements
- python 3.8
- torch 2.3.0
- torchvision 0.18.0
- torchaudio 2.3.0
- timm 0.9.16
- einops 0.8.0
- pytorch_wavelets 1.3.0
- PyWavelets 1.4.1

## Run
``python msffnet.py``
